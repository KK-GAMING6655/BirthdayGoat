Bot Commands

Explore all available member and administrator commands for BirthdayGoat.

Member Commands

/birthday register
<day> <month> [year]

Register your birthday date with optional birth year.

/birthday remove

Remove your registered birthday from the server database.

/birthday list

Displays an organized list of all member birthdays in the server.

Owner & Admin Commands

/set channel
<#channel>

Sets the text channel where daily birthday announcements will be sent.

/set ping
<@role>

Sets a role to ping when sending a birthday announcement.

/set message
[heading] [description] [image_url] [colour] ...

Customize embed headers, footer text, hex colors, images, and thumbnails.

/birthday test

Instantly sends a sample birthday message embed to test settings.
